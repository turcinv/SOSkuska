Aktuální vydání: **v0.18.1**, schéma **10**. Čtyři nálezy Astra jsou vyřešené v [zachovaném záznamu revize](REVIEW_FINDINGS.md). Prioritou je odevzdání semestrální práce podle skutečného zadání.

1. **Potvrdit údaje odevzdání.** Čekají jméno, fakulta/předmět, skupina, schválené téma/další rubrika, termín, jazyk práce a délka prezentace. Dodané PDF neurčuje funkce aplikace ani přesný termín.
2. **Napsat upravitelnou práci.** Použít [kontrolní seznam zadání](SEMESTER_CHECKLIST.md) a [osnovu](REPORT_OUTLINE.md). Příprava je hotová, konečný soubor Word/Writer ještě ne. Cíl je 11 stran hlavního textu, předepsané styly, generovaný obsah/seznamy, skutečné zdroje a obrázky s popisky.
3. **Doplnit skutečné přejímací důkazy.** Zaznamenat [ruční Windows kontroly](WINDOWS_ACCEPTANCE.md), čistý počítač, měřítko, koncepty, obnovu soustředění a zálohu/obnovu. Ověřit skutečný model Ollama a uvést model/verzi, hardware, server a výsledky; falešný server neprokazuje kvalitu modelu.
4. **Ověřit a odevzdat.** Aktualizovat pole dokumentu, prohlédnout strany a započítaný rozsah, použít potvrzené jméno souboru, nacvičit prezentaci a uchovat potvrzení Moodle. Tato dokumentační práce nic neodevzdává ani neposílá e-mailem.

Potvrzení základu v0.15.0 a podmínka sloučení vzhledu byly splněné 22. listopadu; neověřují každé zařízení/položku pro v0.18.1. Odděluj automatické, uživatelem hlášené a ruční důkazy. Nová implementace potřebuje větev, revizi a schválení sloučení/vydání. Viz [poznatky ze sezení](SESSION_LESSONS.md).

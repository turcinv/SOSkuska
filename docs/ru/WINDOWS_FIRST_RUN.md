# Windows с нуля — первый запуск SOSkúška

Инструкция для человека, у которого на Windows 10/11 ещё нет Python или инструментов разработки. Нужны интернет для первой установки и исходные файлы SOSkuska. Git, VS Code, Node.js, Ollama и платные сервисы для нынешнего Dashboard не требуются.

**Важно:** инструкция основана на текущем коде и официальной документации Python. Полное прохождение на настоящей Windows ещё не проверено; собственного установщика `.exe` у приложения пока нет.

## 1. Установи менеджер Python

1. Открой браузер и перейди на [официальную страницу Python для Windows](https://www.python.org/downloads/windows/).
2. Выбери **Python install manager** и скачай его установщик. Менеджер — ещё не нужная версия Python; её добавишь на следующем шаге.
3. Открой скачанный файл и нажми **Install / Установить**. Если есть кнопка **Launch / Запустить**, можешь использовать её для завершения первоначальной настройки.
4. После установки закрой открытые ранее окна терминала.

Не выбирай **embeddable package** или архив исходного кода Python. Здесь используется обычный Python через менеджер согласно [официальной инструкции для Windows](https://docs.python.org/3/using/windows.html).

## 2. Открой PowerShell и добавь Python 3.12

Нажми **Пуск**, введи `PowerShell` и открой **Windows PowerShell** или **Terminal** с профилем PowerShell. Запускать от имени администратора не нужно. Копируй команды по одной строке и подтверждай каждую клавишей Enter. Обозначения `PS>` и тройные обратные кавычки не копируй.

```powershell
py install 3.12
```

Дождись завершения загрузки и установки. Затем проверь версию:

```powershell
py -3.12 --version
```

Ожидаемый результат — `Python 3.12.x`; последняя цифра может отличаться. Намеренно выбираем ветку 3.12, а не автоматически самую новую версию Python.

Если `py install` сообщает о попытке открыть файл `install`, вероятно, используется старое средство запуска. У менеджера есть однозначная команда:

```powershell
pymanager install 3.12
```

Если не распознаются ни `py`, ни `pymanager`, закрой терминал, открой его заново и проверь завершение установки менеджера. Не продолжай, пока проверка версии не заработает.

## 3. Проверь поддержку окон

```powershell
py -3.12 -m tkinter
```

Должно открыться небольшое демонстрационное окно Tk. Закрой его крестиком и вернись в PowerShell. Это подтверждает, что Python умеет создавать окна. Установка одного CustomTkinter не исправит отсутствие модуля `_tkinter`.

## 4. Получи и распакуй проект

Проект доступен в закрытом репозитории [turcinv/SOSkuska](https://github.com/turcinv/SOSkuska): войди под аккаунтом с доступом, нажми **Code → Download ZIP** и распакуй архив. Если доступа нет, попроси у автора архив **SOSkuska-source.zip**. Git не нужен. Архив GitHub обычно содержит папку `SOSkuska-main`; после распаковки переименуй её в `SOSkuska`.

1. Нажми на ZIP правой кнопкой и выбери **Extract All / Извлечь всё**.
2. Найди внутри папку **SOSkuska**, непосредственно содержащую `README.md`, `docs` и подпапку `soskuska`.
3. Перемести её в свою пользовательскую папку. Итоговый путь должен быть `C:\Users\твоё-имя\SOSkuska`.
4. В папке `SOSkuska\soskuska` должны находиться `app.py` и `requirements.txt`. Не перепутай с двойной вложенностью `SOSkuska\SOSkuska\soskuska`.

Проект нужно распаковать, а не открывать прямо внутри ZIP. Виртуальное окружение с Mac не копируй: для Windows создашь новое.

## 5. Перейди в проект

В PowerShell:

```powershell
cd "$HOME\SOSkuska"
Test-Path .\soskuska\app.py
Test-Path .\soskuska\requirements.txt
```

Обе проверки должны вывести `True`. `$HOME` — твоя пользовательская папка, заменять имя пользователя не требуется. Если проект лежит в другом месте, измени путь в `cd` и оставь его в кавычках. При результате `False` сначала найди правильную папку.

## 6. Создай окружение и установи библиотеки

```powershell
py -3.12 -m venv .venv
```

После завершения появится папка `.venv`. Отсутствие вывода без ошибки — нормально. Затем:

```powershell
.\.venv\Scripts\python.exe -m pip install -r soskuska/requirements.txt
```

Дождись успешного завершения установки. Библиотеки устанавливаются в проект, а не глобально. Активировать окружение не нужно; **не меняй PowerShell execution policy**. Если установка закончилась ошибкой, не выполняй следующий шаг вслепую и сохрани полный текст ошибки.

## 7. Запусти приложение

```powershell
.\.venv\Scripts\python.exe soskuska/app.py
```

Должно открыться тёмное окно **SOSkúška** с Dashboard и левой навигацией. Оставь PowerShell открытым: пока приложение работает, новая командная строка не появляется. Для обычного завершения нажми крестик окна приложения.

Работают Dashboard, My Subjects, список задач, поиск и таймер для конкретного предмета. Добавь первый предмет: новая база пустая, а сводка показывает действительно сохранённые данные. Остальные учебные экраны пока запланированы.

## 8. Как запускать в следующий раз

Повторно устанавливать Python, создавать окружение и устанавливать библиотеки не нужно. Открой PowerShell и введи:

```powershell
cd "$HOME\SOSkuska"
.\.venv\Scripts\python.exe soskuska/app.py
```

После успешной первой установки Dashboard не требует интернета. Обычные данные хранятся в `%LOCALAPPDATA%\SOSkuska\dashboard.sqlite3`. Чтобы открыть каталог, вставь `%LOCALAPPDATA%\SOSkuska` в адресную строку Проводника; не удаляй файл, если хочешь сохранить задачи и время.

## 9. Необязательно — разработка и проверка работы

Для экспериментов используй отдельную базу:

```powershell
.\.venv\Scripts\python.exe soskuska/app.py --data .local-data/dev.sqlite3
```

Проверочный скрипт ненадолго откроет окно и использует собственную временную базу:

```powershell
.\.venv\Scripts\python.exe soskuska/check_dashboard.py
```

При успехе он выведет `PASS` и закроет окно. Если проверка или запуск на Windows завершится ошибкой, это важный ещё не проверенный случай — пришли весь вывод, а не только последнюю строку.

## Частые проблемы

| Проблема | Что сделать |
| --- | --- |
| `py` не распознаётся | Заверши установку Python install manager и открой новый PowerShell; проверь также `pymanager` |
| `No suitable Python runtime found` | Выполни `py install 3.12`, при конфликте средств запуска — `pymanager install 3.12` |
| Проверки файлов возвращают `False` | Открыта неправильная папка или ZIP распакован не туда |
| Путь с пробелами не работает | Оставь весь путь в команде `cd` в двойных кавычках |
| `No module named customtkinter` | Повтори установку requirements через `.\.venv\Scripts\python.exe` |
| Отсутствует `_tkinter` | Вернись к установке полного Python и проверке на шаге 3; одного пакета через pip недостаточно |
| PowerShell блокирует `Activate.ps1` | Пропусти активацию; все команды выше запускают `python.exe` напрямую |
| После двойного щелчка окно сразу закрывается | Запусти из PowerShell по шагу 7: ошибка останется видимой |
| Загрузка библиотек не проходит из-за сети | Проверь интернет или корпоративный прокси; не отключай проверку сертификатов |

Дальнейшая работа описана в [руководстве разработчика](DEVELOPMENT.md).


Совместимость с прежним названием: если новой базы в `SOSkuska` нет, а прежняя `ExamPrep/dashboard.sqlite3` существует, приложение использует прежний файл. Оно ничего автоматически не копирует, не перемещает и не перезаписывает. Явный `--data` всегда имеет приоритет.

## Банк тем и вопросов

В My Subjects выбери **Questions** у предмета. Добавь тему через New topic и вопрос через New question. Каждый вопрос содержит четыре разных обязательных ответа A–D, ровно один правильный ответ, сложность Easy/Medium/Hard и необязательное объяснение. Тема необязательна. При ошибке валидации или записи форма сохраняет введённые данные.

Темы можно переименовывать и удалять: выбери тему в фильтре и используй Rename selected topic или Delete selected topic. Вопросы можно изменять и удалять. Поиск по тексту вопроса сочетается с фильтрами темы и сложности. Счётчики в карточках предметов отражают сохранённое содержимое. При удалении темы её вопросы остаются в No topic. Удаление предмета после явного предупреждения удаляет его темы и вопросы, но сохраняет время и историю занятий.

Это редактор содержимого: правильный ответ виден. Запуск и оценивание тренировочных тестов, импорт и изображения пока не реализованы.

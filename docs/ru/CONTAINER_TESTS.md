# Тесты в контейнере

[English](../CONTAINER_TESTS.md) · [Čeština](../cs/CONTAINER_TESTS.md) · [Slovenčina](../sk/CONTAINER_TESTS.md) · [Русский](../ru/CONTAINER_TESTS.md)

Для обычных проверок используй контейнер, чтобы окна GUI не мешали работе на рабочем столе. Docker должен быть установлен, а его движок запущен; проект не устанавливает и не запускает Docker Desktop автоматически. Из корня репозитория:

```sh
docker build -f Dockerfile.tests -t soskuska-tests .
docker run --rm --init --network none --cpus 2 --memory 2g soskuska-tests
```

Сохраняй `--init`: он обеспечивает правильную доставку сигнала запуска виртуальному дисплею и завершение дочерних процессов.

Сборка скачивает Python, системные библиотеки и зависимости, поэтому требует интернет. После изменения исходников пересобери образ: файлы копируются в него, а не подключаются в реальном времени. Повторная сборка использует кеш зависимостей. Тестам нужна только локальная петля для имитации Ollama, поэтому внешняя сеть отключена. Ограничения CPU/памяти уменьшают влияние на другую работу; при необходимости измени их. Дисплей и папки данных хоста не подключаются, порты не публикуются. `.dockerignore` допускает только исходники тестируемого кода; окружения, базы, секреты и история Git остаются вне контекста сборки. После запуска контейнер удаляется, образ и кеш остаются.

Образ работает от обычного пользователя без прав root. Xvfb создаёт внутренний виртуальный экран для каждого GUI-скрипта; окна приложения на хосте не появляются. Общий `tools/run_checks.py` запускает проверку зависимостей, синтаксиса, модульные тесты и GUI-скрипты (382 модульный тест и 26 GUI-скриптов в v0.31.1) с отдельными ограничениями времени. Полный запуск занимает около пяти минут; ошибка возвращает ненулевой код. CI использует тот же список GUI через `--gui-only` после отдельных модульных проверок.

Чтобы запустить один скрипт, переопредели команду; сохрани `--init` и жёсткое ограничение времени:

```sh
docker run --rm --init --network none soskuska-tests timeout 150 xvfb-run -a -s '-screen 0 1920x1080x24' python -X faulthandler -u soskuska/check_note_generation.py
```

Linux-контейнер не проверяет нативный Quit на macOS, трекпад Tk 9 и интерфейс Windows. Нативные проверки Mac нужны только для соответствующих платформенных изменений; видимый запуск сначала согласуй с пользователем. Успешный контейнер не заменяет важную падающую платформенную проверку.

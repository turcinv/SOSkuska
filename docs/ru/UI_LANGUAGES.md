# Язык интерфейса

[English](../UI_LANGUAGES.md) · [Čeština](../cs/UI_LANGUAGES.md) · [Slovenčina](../sk/UI_LANGUAGES.md) · [Русский](UI_LANGUAGES.md)

Выбери **Settings → Interface language (applies after restart)**: English, Čeština, Slovenčina или Русский. Сохрани настройки, заверши или сохрани работу, закрой SOSkúška обычным способом и запусти снова. Язык применяется при запуске. Сохранение не перестраивает экраны, не удаляет черновики и не прерывает занятия или AI. До сохранения выбор остаётся черновиком; другие открытые окна не переключаются.

Языки интерфейса и ответов AI независимы. Можно использовать русский интерфейс и чешские ответы Ollama. Сохранение не подключается к Ollama. Прежние установки по умолчанию запускаются на английском. Выбор относится к выбранной локальной базе и включён в копии.

Навигация, формы, кнопки, сообщения, подтверждения, заголовки просмотра и варианты выбора имеют английский, чешский, словацкий и русский каталоги. Списки показывают переводы, но сохраняют исходные значения для фильтрации, оценки, планирования, моделей и базы. Языки указаны собственными названиями. Неизвестные ошибки системы/сервера сохраняют исходный текст. Системные кнопки файловых диалогов используют язык ОС; заголовки и типы файлов приложения переведены.

Названия предметов/тем/колод, вопросы, ответы, пояснения, содержимое чатов, имена моделей, URL, пути, заголовки CSV и сохранённые даты ISO не переводятся. В неанглийском обзоре дата числовая. Общая локаль процесса не меняется. Кнопки расширяются по тексту; минимум остаётся 1024 × 700, нижнее содержимое доступно прокруткой.

Схема **8** добавляет `preferences.ui_language` с английским значением по умолчанию. Миграция сохраняет данные, историю чатов, язык AI и ревизии настроек. Сохранение явное, атомарное и защищено от устаревшего черновика. Восстановление принимает самостоятельные копии схемы 8; сохрани старый оригинал, открой отдельный дубликат в новой версии через `--data` для миграции и экспортируй новую копию. См. [Резервное копирование](BACKUP_RESTORE.md).

Руководства используют английские подписи UI как общий ориентир. При выборе другого языка приложение показывает соответствующие переводы.

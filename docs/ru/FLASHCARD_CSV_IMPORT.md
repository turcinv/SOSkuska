# Импорт карточек из CSV

[English](../FLASHCARD_CSV_IMPORT.md) · [Čeština](../cs/FLASHCARD_CSV_IMPORT.md) · [Slovenčina](../sk/FLASHCARD_CSV_IMPORT.md) · [Русский](FLASHCARD_CSV_IMPORT.md)

Flashcards теперь поддерживает импорт UTF-8 CSV в существующую колоду: шаблон с заголовками, просмотр по страницам, отклонение точных дубликатов и одно атомарное сохранение. Максимум 2 MiB / 500 записей. Новые карточки сразу доступны для повторения; прежние сроки и история оценок сохраняются. Текущая схема — 8.

1. Открой **Flashcards → Open deck → Import CSV**. Целевая колода должна существовать; для создания новой сначала добавь предмет.
2. Через **Save CSV template** выбери свободное имя файла. Заполни столбцы `front,back` в редакторе или таблице и экспортируй UTF-8 CSV с запятыми; BOM необязателен.
3. Выбери **Choose CSV…** и просмотри карточки через Previous / Next. Исправь все ошибки до включения **Import all**. Просмотр ничего не сохраняет.
4. Выбери **Import all**. Сохраняется всё или ничего. Дождись завершения; новые карточки доступны через **Study due**.

Лицевая сторона обязательна (1–2 000 символов), обратная тоже (1–4 000). Пробелы по краям удаляются. Порядок, регистр и внешние пробелы заголовков могут отличаться; неизвестные и повторные столбцы отклоняются. Запятые и многострочные значения заключай в стандартные кавычки CSV. Пустые записи игнорируются. Точки с запятой, старые кодировки, изображения, автоматическое преобразование вопросов и слияние/обновление не поддерживаются.

Дубликат — точно совпадающие обрезанные лицевая и обратная стороны с учётом регистра, в файле или целевой колоде. Вся группа отклоняется; ничего не пропускается и не перезаписывается. Другая колода может содержать такую же карточку. Идентификатор/имя колоды и дубликаты повторно проверяются под блокировкой записи. Переименованную/удалённую колоду нужно открыть заново и повторить выбор; колода, сохранённая после удаления предмета, остаётся доступной.

Просмотр хранит отдельную группу: изменение исходного файла требует нового **Choose CSV…**. Закрытие импорта и навигация удаляют просмотр. Чтение можно отменить; сохранение блокирует навигацию/Quit. При ошибке записи сохранённую группу можно отправить повторно. После успешной записи и ошибки отчёта используй **Refresh totals**: повторного импорта не будет. Если вспомогательный процесс не подтвердил результат, сначала проверь колоду: группа уже могла сохраниться.

Шаблон содержит только заголовки, публикуется атомарно и не перезаписывает файлы или сопутствующие пути базы. POSIX требует жёстких ссылок; если внешний диск их не поддерживает, используй локальную папку. Чтение и проверка выполняются отдельными процессами; просмотр открывает существующую базу только для чтения без миграции. Без облака, изменения схемы и выдуманных оценок.

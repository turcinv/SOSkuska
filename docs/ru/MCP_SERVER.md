# MCP-сервер только для чтения

[English](../MCP_SERVER.md) · [Čeština](../cs/MCP_SERVER.md) · [Slovenčina](../sk/MCP_SERVER.md) · [Русский](MCP_SERVER.md)

В SOSkúška есть необязательный сервер [Model Context Protocol](https://modelcontextprotocol.io). С ним AI-ассистент, которым вы уже пользуетесь (Claude Desktop, VS Code, Kiro или другой MCP-хост), может **читать** ваши учебные данные: проверять вас по вашим собственным вопросам, видеть, какие карточки пора повторить, и планировать повторение по реальным результатам. Изменить он ничего не может.

## Что он умеет и чего не умеет

- **Только чтение.** Предметы, темы, вопросы, колоды и карточки к повторению, время концентрации, результаты тестов и даты экзаменов. Ни один инструмент не записывает, не удаляет и не импортирует.
- **Ответы по умолчанию скрыты.** Правильные варианты, объяснения и обороты карточек возвращаются только по явному запросу ассистента (например, чтобы проверить ваш ответ). Запуск с `--no-answers` запрещает их полностью.
- **Без сети.** Ассистент запускает сервер как локальную программу и общается с ним через стандартный ввод/вывод. SOSkúška не открывает порт и никуда не подключается.
- **Безопасно рядом с приложением.** Каждый запрос открывает базу только для чтения на мгновение и сразу закрывает. Приложение может оставаться открытым, а бездействующий ассистент никогда не блокирует восстановление из резервной копии; запрос во время восстановления получает сообщение «busy, retry».

**Конфиденциальность:** всё, что возвращает сервер, попадает к модели, которая стоит за вашим ассистентом. Если это облачный сервис, ваши учебные данные попадут к нему. Подключайте только тех ассистентов, с которыми готовы делиться учебными данными.

## Установка

Серверу нужен исходный код (см. [Разработка](DEVELOPMENT.md)); переносной ZIP для Windows его не содержит. Установите необязательную зависимость в то же окружение, которое вы используете для приложения:

```sh
# macOS
.venv-macos/bin/python -m pip install -r soskuska/requirements-mcp.txt
# Windows
.venv\Scripts\python -m pip install -r soskuska\requirements-mcp.txt
```

Проверьте запуск (остановка — Ctrl+C; сервер молча ждёт ассистента):

```sh
.venv-macos/bin/python soskuska/mcp_server.py --data .local-data/dev.sqlite3
```

Без `--data` он читает обычную базу приложения. Базу он никогда не создаёт: сначала один раз откройте приложение.

## Подключение ассистента

Используйте **абсолютные пути** к Python окружения и к `soskuska/mcp_server.py`. В примерах пути macOS; в Windows используйте пути вида `C:\\Users\\you\\SOSkuska\\.venv\\Scripts\\python.exe`.

**Claude Desktop** (`claude_desktop_config.json`) и **Kiro** (`~/.kiro/settings/mcp.json`):

```json
{
  "mcpServers": {
    "soskuska": {
      "command": "/Users/you/SOSkuska/.venv-macos/bin/python",
      "args": ["/Users/you/SOSkuska/soskuska/mcp_server.py"]
    }
  }
}
```

**VS Code** (`.vscode/mcp.json` или пользовательский `mcp.json`):

```json
{
  "servers": {
    "soskuska": {
      "type": "stdio",
      "command": "/Users/you/SOSkuska/.venv-macos/bin/python",
      "args": ["/Users/you/SOSkuska/soskuska/mcp_server.py", "--no-answers"]
    }
  }
}
```

Чтобы использовать другую базу, добавьте в `args` значения `"--data", "/path/to/file.sqlite3"`. Расположение файлов конфигурации меняется между версиями хостов; если файла выше нет, посмотрите документацию своего хоста.

## Инструменты и промпты

| Инструмент | Возвращает |
| --- | --- |
| `list_subjects` | Предметы, даты экзаменов, оставшиеся дни, число тем/вопросов, время концентрации |
| `get_subject` | Темы одного предмета с числом вопросов по сложности |
| `search_questions` | Вопросы предмета, при желании по тексту, теме, сложности или одному точному `question_id`; ответы только с `include_answers` |
| `list_decks` / `due_flashcards` | Колоды с числом карточек к повторению; карточки к повторению, обороты только с `include_backs` |
| `study_statistics` | Время концентрации, взвешенная точность тестов и самооценки карточек за Last 7 days, Last 30 days или All time |
| `practice_history` | Завершённые тесты с результатами по темам, под названием предмета на момент теста |
| `upcoming_exams` | Экзамены начиная с сегодняшнего дня |

Промпты: **Quiz me** (по одному вопросу, ответ — только после вашего ответа) и **Weak topics study plan**. Ресурс `soskuska://subjects` даёт краткий обзор в Markdown.

Результаты небольшие, чтобы поместиться в контекст модели: списки ограничены 50 элементами (экзамены — 20) и примерно 20 КБ, длинные описания сокращаются; и то и другое помечается `truncated`. Вопросы и карточки всегда возвращаются целиком.

## Устранение неполадок

- **«needs the optional 'mcp' package»** — установите `requirements-mcp.txt` в тот Python, который указан в конфигурации хоста.
- **«no SOSkúška database»** — один раз откройте приложение или укажите правильный путь `--data`.
- **«busy»** — идёт восстановление или другая монопольная операция; повторите чуть позже.
- **«Open SOSkúška once to update it»** — база принадлежит другой версии приложения; откройте приложение, чтобы оно её обновило.

Удаление: удалите запись `soskuska` из конфигурации хоста. При желании удалите пакет командой `python -m pip uninstall mcp`.

## Состояние проверки

Автоматические тесты (клиент в процессе — в текущем протоколе без состояния и в старом рукопожатии — и настоящий подпроцесс через stdio) покрывают каждый инструмент, скрытые ответы, `--no-answers`, лимиты, ошибки busy/схемы/отсутствующей базы и неизменный файл базы. Записанного запуска с настоящим ассистентом пока нет.

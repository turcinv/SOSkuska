# Приёмочная проверка Windows

[English](../WINDOWS_ACCEPTANCE.md) · [Čeština](../cs/WINDOWS_ACCEPTANCE.md) · [Slovenčina](../sk/WINDOWS_ACCEPTANCE.md) · [Русский](../ru/WINDOWS_ACCEPTANCE.md)

Статус на 22 ноября 2026 года: пользователь подтвердил завершение проверки v0.15.0 и разрешил PR #32. Этот список теперь относится к v0.31.1; отдельные результаты чистого компьютера/DPI здесь не записаны. Непомеченные пункты остаются непроверенными; при проверке нового выпуска добавь доказательства для конкретного устройства.

Запиши редакцию/сборку Windows, архитектуру CPU, разрешение/масштаб, коммит артефакта, SHA-256, дату, проверяющего и результаты. Приложи снимки экрана и воспроизведение ошибок. Каждый пункт пометь PASS/FAIL с доказательством; непомеченный пункт не проверен.

- [ ] Скачать, сверить хеш, распаковать оба ZIP и запустить без Python/прав администратора.
- [ ] Пустой старт без примеров предметов, баллов и времени; проверить путь данных и перезапуск.
- [ ] Создать/изменить Unicode-предмет, тему и вопрос с четырьмя вариантами; поиск/фильтры и перезапуск.
- [ ] Импортировать CSV вопросов/карточек, отклонить неверный файл, отменить просмотр, безопасно повторить ошибочную запись.
- [ ] Создать/раскрыть/оценить карточки и проверить сохранённые сроки/историю.
- [ ] Тест со временем/без: сохранить ответы, закрыть/продолжить, завершить и разобрать результат. Просмотреть более 20 попыток и фильтры истории.
- [ ] Запустить/приостановить/завершить занятие; проверить реальное сохранённое время и Statistics.
- [ ] Сохранить/перезапустить все четыре языка; проверить длинные надписи/кириллицу, исходное содержимое и отдельный язык AI.
- [ ] В 1440×900 и 1024×700 проверить размер окна, вложенную прокрутку, клавиатуру, диалоги и доступный масштаб 100/125/150 %.
- [ ] Без Ollama/сети обучение работает. Если доступна, явно подключить реальную модель, проверить поток/Stop/переподключение и сохранённый чат; отдельно записать модель/оборудование.
- [ ] Копия/проверка/восстановление временных данных, страховочная копия, закрытие и проверка после перезапуска; другие экземпляры перед восстановлением закрыть.
- [ ] Закрыть через заголовок и панель задач, открыть снова; перенести/обновить папку приложения без потери данных. Проверить второй экземпляр/блокировку данных и понятную ошибку.

Используй [переносимую версию](WINDOWS_PORTABLE.md) или [запуск исходников](https://github.com/turcinv/SOSkuska/blob/main/docs/ru/WINDOWS_FIRST_RUN.md). Размещённый CI проверяет запуск/помощники; он не отмечает этот ручной список выполненным.

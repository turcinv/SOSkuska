# SOSkúška — документация на русском языке

**Выпуск: [v0.3.0](https://github.com/turcinv/SOSkuska/releases/tag/v0.3.0)** — исходный код работающего прототипа. Список функций и исправлений — в [истории изменений](CHANGELOG.md). Установщик пока не входит в выпуск.

Локальное настольное приложение для подготовки к экзаменам на Python и CustomTkinter. Реализованы Dashboard и My Subjects: управление предметами и датами экзаменов, ежедневный список задач, поиск и таймер с привязкой к предмету. Задачи и время занятий сохраняются в SQLite на устройстве пользователя.

**Состояние: работающий прототип с реальными локальными данными.** Предметы можно создавать, изменять и удалять; сводка использует сохранённое время и даты. Новая база пустая. AI Tutor, тесты и карточки пока не реализованы. Для работы не нужны Superdesign, платный API или интернет.

## Клонирование и первая установка

Репозиторий закрытый: нужны Git и аккаунт с доступом. В терминале перейди в папку, где хочешь разместить проект:

```sh
git clone https://github.com/turcinv/SOSkuska.git
cd SOSkuska
```

Клон не содержит окружения Python или базы. Продолжи по [инструкции установки для своей системы](DEVELOPMENT.md). Установка Git, авторизация, обновления и работа с ветками описаны в [пошаговом руководстве Git](GIT_GUIDE.md).

## Быстрый запуск на этом Mac

Из корневой папки проекта:

```sh
.venv-macos/bin/python soskuska/app.py
```

Или открой `soskuska/run-macos.command`. Подготовленное окружение использует Python 3.12.13 / Tk 9.0. Старое `.venv-desktop` не используй: на этом Mac оно показывало пустое окно.

## Банк тем и вопросов

В My Subjects выбери **Questions** у предмета. Добавь тему через New topic и вопрос через New question. Каждый вопрос содержит четыре разных обязательных ответа A–D, ровно один правильный ответ, сложность Easy/Medium/Hard и необязательное объяснение. Тема необязательна. При ошибке валидации или записи форма сохраняет введённые данные.

Темы можно переименовывать и удалять: выбери тему в фильтре и используй Rename selected topic или Delete selected topic. Вопросы можно изменять и удалять. Поиск по тексту вопроса сочетается с фильтрами темы и сложности. Счётчики в карточках предметов отражают сохранённое содержимое. При удалении темы её вопросы остаются в No topic. Удаление предмета после явного предупреждения удаляет его темы и вопросы, но сохраняет время и историю занятий.

Это редактор содержимого: правильный ответ виден. Запуск и оценивание тренировочных тестов, импорт и изображения пока не реализованы.

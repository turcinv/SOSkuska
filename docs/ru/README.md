# SOSkúška — документация на русском языке

Локальное настольное приложение для подготовки к экзаменам на Python и CustomTkinter. Сейчас реализована главная страница Dashboard с ежедневным списком задач, поиском предметов и таймером. Задачи и время занятий сохраняются в SQLite на устройстве пользователя.

**Состояние: работающий прототип Dashboard.** Предметы, экзамены, профиль и часть статистики — демонстрационные данные. AI Tutor, тесты и карточки пока не реализованы. Для работы не нужны Superdesign, платный API или интернет.

## Быстрый запуск на этом Mac

Из корневой папки проекта:

```sh
.venv-macos/bin/python soskuska/app.py
```

Или открой `soskuska/run-macos.command`. Подготовленное окружение использует Python 3.12.13 / Tk 9.0. Старое `.venv-desktop` не используй: на этом Mac оно показывало пустое окно.

## Папки и платформы

```text
soskuska/          Нативное приложение и проверочный скрипт
soskuska-local/    Отдельный старый HTML-макет; визуальный образец
docs/             Чешская документация; sk/ словацкая, ru/ русская
```

Основные целевые платформы — Windows/Linux; macOS также используется для разработки. Нативная проверка прошла на macOS, Windows/Linux ещё не проверены. Установщика пока нет. Отдельный репозиторий: [turcinv/SOSkuska](https://github.com/turcinv/SOSkuska). Он закрытый; для доступа нужны соответствующие права.

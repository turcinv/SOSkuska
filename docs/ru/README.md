# SOSkúška — документация на русском языке

[English](../../README.md) · [Čeština](../cs/README.md) · [Slovenčina](../sk/README.md) · [Русский](README.md)

**Выпуск: [v0.8.1](https://github.com/turcinv/SOSkuska/releases/tag/v0.8.1)** — исходный код работающего прототипа. Список функций и исправлений — в [истории изменений](CHANGELOG.md). Установщик пока не входит в выпуск.

Локальное настольное приложение для подготовки к экзаменам на Python и CustomTkinter. Реализованы Dashboard и My Subjects: управление предметами и датами экзаменов, ежедневный список задач, поиск и таймер с привязкой к предмету. Задачи и время занятий сохраняются в SQLite на устройстве пользователя.

**Состояние: работающий прототип с реальными локальными данными.** Предметы можно создавать, изменять и удалять; сводка использует сохранённое время и даты. Новая база пустая. AI Tutor предлагает необязательный чат сеанса через Ollama. Для работы не нужны Superdesign, платный API или интернет.

## Клонирование и первая установка

Репозиторий закрытый: нужны Git и аккаунт с доступом. В терминале перейди в папку, где хочешь разместить проект:

```sh
git clone https://github.com/turcinv/SOSkuska.git
cd SOSkuska
```

Клон не содержит окружения Python или базы. Продолжи по [инструкции установки для своей системы](DEVELOPMENT.md). Установка Git, авторизация, обновления и работа с ветками описаны в [пошаговом руководстве Git](GIT_GUIDE.md).

## Быстрый запуск на этом Mac

Из корневой папки проекта:

```sh
.venv-macos/bin/python soskuska/app.py
```

Или открой `soskuska/run-macos.command`. Подготовленное окружение использует Python 3.12.13 / Tk 9.0. Старое `.venv-desktop` не используй: на этом Mac оно показывало пустое окно.

## Банк тем и вопросов

В My Subjects выбери **Questions** у предмета. Добавь тему через New topic и вопрос через New question. Каждый вопрос содержит четыре разных обязательных ответа A–D, ровно один правильный ответ, сложность Easy/Medium/Hard и необязательное объяснение. Тема необязательна. При ошибке валидации или записи форма сохраняет введённые данные.

Темы можно переименовывать и удалять: выбери тему в фильтре и используй Rename selected topic или Delete selected topic. Вопросы можно изменять и удалять. Поиск по тексту вопроса сочетается с фильтрами темы и сложности. Счётчики в карточках предметов отражают сохранённое содержимое. При удалении темы её вопросы остаются в No topic. Удаление предмета после явного предупреждения удаляет его темы и вопросы, но сохраняет время и историю занятий.

Это редактор содержимого: правильный ответ виден. Тренировки и оценивание доступны в Practice Tests. Импорт и изображения пока не реализованы.

## Practice Tests — тренировки (v0.4.0)

Сначала создай предмет и вопросы через My Subjects → Questions. В Practice Tests выбери предмет, тему (все / без темы / конкретная), сложность и 1–100 доступных вопросов. Необязательный лимит — 5, 10, 15, 30 или 60 минут; Untimed означает отсутствие лимита. Вопросы выбираются случайно без повторов.

Ответ сохраняется после каждого выбора; его можно изменить или очистить через Clear answer. Previous/Next меняют сохранённую позицию. При возврате или перезапуске можно продолжить через Resume test. Одновременно допускается один незавершённый тест. Discard test требует подтверждения и удаляет только эту незавершённую попытку.

Finish test после подтверждения сохраняет результат; пропущенные вопросы считаются неправильными. Правильные ответы и объяснения появляются только после сдачи. Время продолжает идти вне экрана и при закрытом приложении; после истечения тест автоматически завершается при работе или возврате в приложение. Результат и вопросы являются снимком на начало попытки: последующее изменение или удаление исходного содержимого их не меняет. История показывает последние 20 завершённых тестов; более старые записи остаются в базе.

Тренировки доступны начиная с v0.4.0. Тренировки не добавляют выдуманное время в суммы таймера. Импорт остаётся в плане; у AI Tutor есть необязательный чат; общий обзор доступен в Statistics.

## Карточки и повторение (v0.5.0)

В боковом меню открой **Flashcards**. New deck создаёт колоду для существующего предмета; название должно быть уникальным среди всех колод. Предмет колоды затем не меняется, название и описание менять можно. Open deck позволяет добавлять и редактировать карточки. Лицевая сторона содержит 1–2000 символов, обратная — 1–4000; Search ищет по обеим сторонам. Список показывает максимум 100 результатов, остальные можно найти более узким поиском.

[Подробная инструкция и правила](FLASHCARDS.md).

## Статистика (v0.6.0)

В меню **Statistics** выбери Last 7 days, Last 30 days или All time. Экран показывает сохранённое время и занятия, точность завершённых тестов с равным весом вопросов, число собственных оценок карточек, время по предметам и активность по дням. Refresh или возвращение на экран загружает новый снимок. Это не измерение освоения материала.

[Подробные правила](STATISTICS.md).

## AI Tutor с Ollama (v0.7.0)

В AI Tutor подключи свой сервер Ollama через Connect / refresh, выбери модель и язык ответа и задай вопрос. Ответ поступает постепенно; Stop останавливает его. Остальные экраны доступны во время генерации и без Ollama. Чат существует только в текущем сеансе приложения и не сохраняется в базе.

[Руководство AI Tutor](AI_TUTOR.md).

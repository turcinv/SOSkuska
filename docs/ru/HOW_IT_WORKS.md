# Как это работает — простое объяснение

SOSkuska — настольное приложение. Python с помощью CustomTkinter создаёт окно и элементы управления. Браузер и веб-сервер для этого не нужны. HTML в папке `soskuska-local/` — отдельный макет внешнего вида.

## От запуска до сохранения данных

1. **Запуск:** приложение создаёт окно и открывает локальную базу SQLite. Если её ещё нет, создаёт её.
2. **Список задач:** отмечаешь задачу, и изменение сразу сохраняется с сегодняшней датой. После повторного запуска в тот же день отметка останется.
3. **Поиск:** вводишь, например, `Physics`. Приложение фильтрует четыре демонстрационных предмета в памяти; в интернет ничего не отправляется.
4. **Занятие:** Start Studying и Resume session запускают новый таймер на 15 минут. Его можно приостановить и продолжить.
5. **Завершение:** Finish сохраняет фактически прошедшие секунды. Через 15 минут занятие завершается автоматически. Обычное закрытие окна тоже сохраняет прошедшее время.

Таймер не восстанавливается между запусками. При принудительном завершении или сбое время незаконченного занятия может потеряться: промежуточное сохранение пока не реализовано.

## Реальные функции и демонстрационные данные

| Действительно работает | Пока только пример |
| --- | --- |
| Ежедневный список задач и его сохранение | Профиль Alex Morgan |
| Измерение и сохранение времени занятий | Серия учебных дней, число вопросов и точность ответов |
| Фильтрация, прокрутка и изменение расположения элементов | Предметы и проценты прогресса |
| Пауза и завершение таймера | Даты экзаменов и недавняя активность |

В основе сводки пока лежат демонстрационные **24 ч 35 мин всего** и **45 мин сегодня**. Реально сохранённое время прибавляется к этим значениям. Это ещё не полная статистика твоих занятий.

На Mac база по умолчанию находится в `~/Library/Application Support/SOSkuska/dashboard.sqlite3`. Автоматической синхронизации нет. Само приложение базу не шифрует.

## Что появится позже

Можно будет добавлять свои предметы, вопросы и карточки. Тренировки начнут сохранять ответы, а сводка — показывать реальный прогресс. AI Tutor подключится к локальной Ollama, которая запускает языковую модель. Обычные занятия должны оставаться доступными и без AI.

Это будущий план, а не сегодняшние функции. Остальные пункты навигации пока только показывают сообщение о будущей доступности.


Совместимость с прежним названием: если новой базы в `SOSkuska` нет, а прежняя `ExamPrep/dashboard.sqlite3` существует, приложение использует прежний файл. Оно ничего автоматически не копирует, не перемещает и не перезаписывает. Явный `--data` всегда имеет приоритет.

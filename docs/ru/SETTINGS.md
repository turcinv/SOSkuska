# Настройки

[English](../SETTINGS.md) · [Čeština](../cs/SETTINGS.md) · [Slovenčina](../sk/SETTINGS.md) · [Русский](SETTINGS.md)

Настройки сохраняются в той же базе, что и учебные данные.

В **Settings** задай длительность следующего focus-занятия (1–180 минут, по умолчанию 15), дневную цель (1–1 440 минут, по умолчанию 60), URL Ollama, предпочтительную модель и язык AI-ответов. **Save settings** сохраняет и применяет все значения; черновик сохраняется при переходе между экранами, но теряется при закрытии приложения. Текущее занятие, включая паузу, сохраняет исходную длительность. Цель меняется сразу, история времени не пересчитывается.

**Use Tutor choices** только копирует текущие параметры AI Tutor в форму; затем нажми Save settings. Прямые изменения в AI Tutor временные. Сохранение, запуск и переход на экран не создают сетевое подключение. Подключись явно через Connect / refresh. Недоступная предпочтительная модель не заменяется другой без выбора пользователя. Язык относится к AI-ответам, а не к интерфейсу приложения.

Дождись завершения AI-запроса или нажми Stop перед изменением AI-параметров. Учебные параметры можно сохранять и во время запроса. Если чат относится к другому серверу, сначала очисти его через New chat с подтверждением. Сохранение уже подключённого сервера сохраняет его чат. Закрытие приложения по-прежнему удаляет чат.

Ошибка записи или конфликт с другим окном не удаляет черновик. Перед Reload скопируй его; замена изменённой формы требует второго нажатия. Изменения другого окна не применяются автоматически: в этом окне их применит Save или перезапуск. Save применяет все загруженные значения, включая AI-параметры другого окна, поэтому могут действовать указанные ограничения. Некорректные сохранённые настройки показываются как безопасные значения по умолчанию; исправление происходит только после явного Save.

Настройки локальны для выбранной базы (`--data`), без синхронизации и шифрования. Выбор оформления, переводы UI и сохранение AI-разговоров ещё не реализованы.

При подключении к другому серверу модель выбирается заново по сохранённому предпочтению. Обновление того же сервера сохраняет вручную выбранную доступную модель.

## Резервное копирование и восстановление

Settings теперь предлагает ручное локальное копирование и проверенное восстановление со страховочной копией перед заменой. Схема остаётся 6. Восстановление закрывает приложение; затем запусти его снова. См. [Резервное копирование](BACKUP_RESTORE.md).

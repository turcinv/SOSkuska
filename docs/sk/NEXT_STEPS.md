Aktuálne vydanie: **v0.18.1**, schéma **10**. Štyri nálezy Astra sú vyriešené v [zachovanom zázname revízie](REVIEW_FINDINGS.md). Prioritou je odovzdanie semestrálnej práce podľa skutočného zadania.

1. **Potvrdiť údaje odovzdania.** Čakajú meno, fakulta/predmet, krúžok, schválená téma/ďalšia rubrika, termín, jazyk práce a dĺžka prezentácie. Dodané PDF neurčuje funkcie aplikácie ani presný termín.
2. **Napísať upraviteľnú prácu.** Použiť [kontrolný zoznam zadania](SEMESTER_CHECKLIST.md) a [osnovu](REPORT_OUTLINE.md). Príprava je hotová, konečný súbor Word/Writer ešte nie. Cieľ je 11 strán hlavného textu, predpísané štýly, generovaný obsah/zoznamy, skutočné zdroje a obrázky s popismi.
3. **Doplniť skutočné akceptačné dôkazy.** Zaznamenať [ručné Windows kontroly](WINDOWS_ACCEPTANCE.md), čistý počítač, mierku, koncepty, obnovu sústredenia a zálohu/obnovu. Overiť skutočný model Ollama a uviesť model/verziu, hardvér, server a výsledky; falošný server nepreukazuje kvalitu modelu.
4. **Overiť a odovzdať.** Aktualizovať polia dokumentu, prezrieť strany a započítaný rozsah, použiť potvrdené meno súboru, nacvičiť prezentáciu a uchovať potvrdenie Moodle. Táto dokumentačná práca nič neodovzdáva ani neposiela e-mailom.

Potvrdenie základu v0.15.0 a podmienka zlúčenia vzhľadu boli splnené 22. novembra; neoverujú každé zariadenie/položku pre v0.18.1. Oddeľuj automatické, používateľom hlásené a ručné dôkazy. Nová implementácia potrebuje vetvu, revíziu a schválenie zlúčenia/vydania. Pozri [poznatky zo sedenia](SESSION_LESSONS.md).

# Preberacia kontrola Windows

[English](../WINDOWS_ACCEPTANCE.md) · [Čeština](../cs/WINDOWS_ACCEPTANCE.md) · [Slovenčina](../sk/WINDOWS_ACCEPTANCE.md) · [Русский](../ru/WINDOWS_ACCEPTANCE.md)

**Ručná kontrola na čistom počítači: NEVYKONANÁ.** Automatické CI protokoly sú samostatný dôkaz. Vyplň tento záznam na Windows x64 bez nainštalovaného Pythonu s presným overeným artefaktom. Nepoužívaj skutočné/súkromné študijné dáta.

Zaznamenaj edíciu/build Windows, architektúru CPU, rozlíšenie/mierku, commit artefaktu, SHA-256, dátum, testujúceho a výsledky. Prilož snímky a postup reprodukcie chýb. Každý bod označ PASS/FAIL s dôkazom; nezaškrtnutý nie je overený.

- [ ] Stiahnuť, overiť kontrolný súčet, rozbaliť oba ZIPy a spustiť bez Pythonu/práv správcu.
- [ ] Prázdny štart bez vzorových predmetov, skóre a času; overiť cestu k dátam a reštart.
- [ ] Vytvoriť/upraviť Unicode predmet, tému a otázku so štyrmi možnosťami; hľadať/filtrovať a reštartovať.
- [ ] Importovať CSV otázok/kartičiek, odmietnuť chybný súbor, zrušiť náhľad a bezpečne zopakovať chybný zápis.
- [ ] Vytvoriť/odhaliť/ohodnotiť kartičky a overiť uložené termíny/históriu.
- [ ] Časovaný/nečasovaný test: uložiť odpovede, zavrieť a pokračovať, dokončiť a prezrieť výsledok. Prejsť viac než 20 pokusov a filtrovať históriu.
- [ ] Spustiť/pozastaviť/dokončiť sústredenie; overiť skutočný uložený čas a Statistics.
- [ ] Uložiť/reštartovať všetky štyri jazyky; overiť dlhé popisy/azbuku, pôvodný obsah a samostatný jazyk AI.
- [ ] V 1440×900 a 1024×700 overiť zmenu veľkosti, vnorené posúvanie, klávesnicu, dialógy a podporované mierky 100/125/150 %.
- [ ] Bez Ollamy/offline musí fungovať štúdium. Ak je dostupná, výslovne pripojiť reálny model, stream/Stop/opätovné pripojenie a uložený chat; zapísať model a hardvér zvlášť.
- [ ] Záloha/validácia/obnova dočasných dát, bezpečnostná kópia, zatvorenie a kontrola po reštarte; ostatné inštancie pri obnove zavrieť.
- [ ] Zavrieť cez titulnú lištu aj panel úloh a otvoriť znova; presunúť/aktualizovať aplikáciu bez straty dát. Vyskúšať druhú inštanciu/zamknuté dáta a užitočnú chybu.

Použi [prenosnú verziu](WINDOWS_PORTABLE.md) alebo [spustenie zo zdrojov](https://github.com/turcinv/SOSkuska/blob/main/docs/sk/WINDOWS_FIRST_RUN.md). Hostované CI overuje štart/pomocníkov; neoznačuje tento ručný zoznam za dokončený.
